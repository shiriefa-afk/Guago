AG KARYANA HITUNG BELANJA — PROYEK ANDROID

Ini adalah proyek sumber Android Studio yang membungkus aplikasi HTML lokal menjadi aplikasi Android dengan ikon AG KARYANA.

FITUR:
- Input banyak barang
- Harga dan subtotal otomatis
- Total belanja
- Input uang masuk
- Kembalian otomatis atau indikator uang kurang
- Simpan daftar harga dan riwayat di penyimpanan browser lokal
- Salin nota untuk WhatsApp

PENTING:
Paket ini adalah SOURCE PROJECT untuk membangun APK, bukan file APK siap pasang. Lingkungan pembuat file ini tidak memiliki Android SDK/Gradle yang diperlukan untuk mengompilasi APK secara langsung.

CARA MEMBUAT APK:
1. Di komputer, instal Android Studio dari situs resmi Android Developers.
2. Ekstrak ZIP proyek ini.
3. Buka Android Studio > Open, lalu pilih folder AGKaryanaAndroid hasil ekstrak.
4. Tunggu Gradle Sync selesai. Jika diminta, instal Android SDK Platform 35 dan Android Gradle Plugin yang disarankan Android Studio.
5. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Setelah selesai, tekan Locate pada notifikasi hasil build. APK debug biasanya berada di app/build/outputs/apk/debug/app-debug.apk.
7. Pindahkan APK ke HP Android dan buka untuk memasang. Jika diminta, izinkan instalasi dari sumber tersebut hanya untuk aplikasi/file yang Anda percaya.

CATATAN:
- Harga contoh awal harus diperiksa dan disesuaikan.
- Data disimpan lokal di WebView aplikasi; jangan hapus data aplikasi jika ingin mempertahankan riwayat.
- Untuk distribusi luas, buat signed release APK dengan kunci rilis sendiri dan simpan kunci dengan aman.
